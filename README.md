# Campus-Life-Planner
A responsive student planner for managing campus tasks, events, and deadlines.
1. Features
Add, edit, and delete activities.
Search and sort activities.
Track upcoming deadlines and activity statistics.
Save activities using local storage.
Import and export activities as JSON.
Responsive layout for different screen sizes.
Validate form inputs.

2. Open the project folder in VS Code.
Start Live Server from index.html.
Open tests.html with Live Server to run the tests.
